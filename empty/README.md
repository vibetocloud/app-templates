# __APP_NAME__

An empty Vibe to Cloud starter — a single static page (the logo on a background),
served by nginx. No build step, no backend, no database. It exists to get you a
live URL in seconds so you can start editing with Claude Code.

## What's here

- `index.html` — the page you see when the app is live.
- `nginx.conf` / `Dockerfile` — serve the static file on port 3000.
- `docker-compose.yml` — one `web` service.

## Make it yours

Connect Claude Code and ask it to change anything — the heading, the colours, or
turn it into a real app. Every change redeploys to your live URL.
